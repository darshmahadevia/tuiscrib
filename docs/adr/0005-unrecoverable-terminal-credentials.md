# Use unrecoverable terminal-only credentials

Users register and sign in entirely in the terminal with an immutable username and a confirmed 8-128 character Unicode password; the service collects no email address and offers no password-recovery mechanism. One opaque session token persists in a protected platform config file until sign-out or 30 days of inactivity. Losing both the password and session permanently loses access, an accepted simplification for the Source-First Portfolio Demo.
